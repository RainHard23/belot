# Статус проекта — Билот 1×1

Последнее обновление: 6 августа 2026.

Онлайн-белот 1×1: React + Vite + Tailwind + Motion + Zustand на клиенте,
NestJS + Socket.IO на сервере, общее игровое ядро в `shared/game` (Vitest).

## ✅ Сделано

### Игровое ядро и сервер

- Полные правила Белота 1×1: раздача 6 → открытая карта → классический
  торг (круг 1 «взять/пас», круг 2 «назвать другую масть/пас», иначе
  пересдача) → добор до 9 (прикуп 6) → игра до последней взятки.
- Подсчёт очков (162 → 16 пунктов, округление «на 6»), объявы (белла,
  терц, 50/100, четвёрки, шестерка простая, билот), болты, ничья по
  пунктам, аннулирование объявов.
- `shared/game` — чистое ядро без UI-зависимостей, покрыто Vitest.
- NestJS-гейтвей (`server/src/game.gateway.ts`): валидация входящих
  сообщений, одна сессия — один стол, `OnGatewayDisconnect` с grace-периодом
  на реконнект, восстановление приватной руки по сессии.
- `LobbyService` / `MatchService` / `SessionService`: жизненный цикл
  матча (создание/окончание/очистка), авторизация действий по seat,
  санитайз имени игрока, единая сессия на стол.
- Событийный протокол анимаций: сервер диффует предыдущее/текущее
  состояние (`shared/game/anim.ts` → `deriveAnimEvents`) и шлёт клиенту
  список событий вместо того, чтобы клиент угадывал анимацию по дельте
  состояния.
- **Тестовый стол «Играть с ботом»**: `lobby:practice` сажает игрока одного
  за первый свободный стол и досаживает виртуального бота вторым игроком.
  `BotService` реагирует на `poke()` после каждого хода/торга и делает
  случайный легальный ход через тот же `MatchService.doBid`/`doPlay`, что
  и настоящий игрок. Бот иногда шлёт эмоцию после своего хода, чтобы соло
  не выглядело мёртвым.
- **Серверный таймер хода** (`server/src/match/turn-timer.service.ts`):
  20 секунд на ход человека (боту таймер не нужен — им управляет
  `BotService`). По истечении — авто-пас в торге или случайная легальная
  карта в игре (`turn-timer-logic.ts`, чистая функция, покрыта юнит-тестами
  через `decideTimeout`). Дедлайн (`turnDeadlineAt`, epoch ms) едет в каждом
  `match:state`, `SeatPod` рисует от него настоящее кольцо, а не
  косметический таймер.
- **Сетевые эмоции** (`shared/net/protocol.ts` + `match:emote`): закрытый
  список эмодзи, авторизация через `seatOf`, rate-limit 5/10с на сессию
  (`server/src/rate-limiter.ts`, `SlidingWindowLimiter` — чистый класс,
  юнит-тестирован отдельно от Nest). Оба игрока в комнате `match:<id>`
  видят реакции друг друга в реальном времени.

### Клиент — общее

- Русская локализация всего UI (`src/ui/i18n/ru.ts`).
- `NameGate` — экран ввода имени перед лобби, имя живёт в `sessionStorage`.
- Клиентская очередь анимаций (`animationQueue.ts`) с `reset()`, уважает
  `prefers-reduced-motion` **и** ручной оверрайд из `settingsStore`.
- Обработка ошибок сервера как всплывающий тост.
- **Локальные шрифты**: Nunito (400/600/700/800, latin+cyrillic, woff2)
  лежит в `public/fonts/`, `@font-face` в `src/index.css`, зависимость от
  `fonts.googleapis.com` полностью убрана из `index.html`.
- **UI-токены**: `--gold-1/2/3`, `--accent`, `--accent-soft`, `--accent-ring`,
  `--panel-*` объявлены в `:root` (баг — `var(--gold-2)` использовался в 28
  местах, но не был объявлен ни разу, — исправлен) и переопределяются в
  каждом `[data-table-theme]`, так что акцент всего HUD, а не только сукна,
  меняется вместе с темой стола.

### Стол и HUD — «Идеальный интерфейс за столом»

- **Детерминированная сетка** (`src/ui/match/stageLayout.ts` +
  `MatchScreen.tsx`): явные grid-строки `hud / seat / felt / dock / hand`.
  Только строка стола — `minmax(0, 1fr)`, остальные фиксированы или `auto`.
  Все игровые якоря (карты соперника, центр взятки) — проценты **от
  собственного бокса строки стола**, а не от вьюпорта, поэтому изменение
  высоты HUD/дока больше не двигает стол (баг «оно опускает вниз» устранён
  в корне, а не костылём через `absolute`).
- **Игровая дизайн-система** (`src/ui/match/controls/`): `ActionButton`
  (варианты take/suit/pass/primary/ghost на CVA, «физический» стиль с
  бликом/тенью/press-down), `IconButton`, `Pill`, `Panel` (общий стеклянный
  контейнер на токенах — `ScorePanel`/`HintsPanel`/`HandLogPanel`/
  `EmotePanel` переведены на него), `Popover`, `Tooltip`.
- **Горячие клавиши**: `Enter` — взять (1 круг торга), `Esc` — пас, `1–4` —
  выбор козыря (2 круг), `←/→` — навигация по руке, `Enter` — сыграть
  выбранную карту, `?` — шпаргалка.
- **`settingsStore`** (zustand + localStorage, миграция со старого ключа
  `bilot_table_theme`): тема стола, звук вкл/выкл + громкость, показывать
  подсказки, размер карт, левша/правша (зеркалит боковые панели),
  ручной оверрайд reduced-motion. Поповер настроек в HUD.
- **Реальный таймер хода**: `SeatPod` рисует SVG-кольцо от настоящего
  `turnDeadlineAt`, краснеет и ускоряется на последних 5 секундах; локальный
  `timeout`-сигнал (звук/подсказка) срабатывает, когда кольцо у вас
  визуально опустело.
- **Game feel**: победа во взятке — вспышка на аватаре + анимированное
  «+1» к счётчику взяток; `aria-live`-регион озвучивает смену фазы/хода для
  скринридеров; `HandEndPanel` — центральный модальный оверлей (не часть
  бегущей сетки) с разбивкой очков, прогрессом до `target` и
  автопродолжением через 8с с видимым таймингом на кнопке; матч-овер —
  полноэкранный оверлей с CSS-конфетти (без canvas/зависимостей) при победе.
- **Звук** (`src/ui/audio/soundBus.ts`): WebAudio с unlock по первому клику,
  10 реальных CC-сэмплов в `public/sfx/*.mp3` (Mixkit, лицензия допускает
  использование без атрибуции) на deal/bid/trump/play/trick/hand_end/
  declaration/win/lose/timeout, с фолбэком на синтезированный тон
  (`OscillatorNode`), если файл не загрузился — звук никогда не «просто
  ломается» молча.
- **Стол**: специальный блик сверху (`mix-blend-screen`), кожаная строчка
  рейла (dashed inset), зона трюка, маркеры мест, медальон перекрашен в
  `--accent` (раньше был на несуществующей переменной и не отображался).

### Комната вокруг стола (`src/ui/match/room/`)

Раньше «окружение» было одним JPG `1024x683`, растянутым `bg-cover` на
1920+, под шестью затемняющими слоями — детали гасились в чёрный, поэтому
фон и не менялся визуально, что бы за него ни ставили. Заменено настоящей
CSS-3D комнатой:

- **`roomGeometry.ts`** — единственный источник чисел сцены (горизонт,
  наклон пола, ширина комнаты, фокусное расстояние). Ключевой инвариант
  задокументирован там же: горизонт (22% высоты) всегда выше дальнего рейла
  стола на всех разрешениях, поэтому стол читается стоящим *перед* стеной, а
  не сквозь неё.
- **Пол** — реальная 3D-плоскость (`rotateX(76deg)` вокруг линии горизонта)
  с тайловым материалом: перспектива сама сжимает тайл к горизонту, поэтому
  апскейла нет ни на 720p, ни на 4K. Фокусное расстояние задано в `cqh`, а
  не в px: с фиксированными px плоскость на высоких вьюпортах пересекала
  плоскость камеры и рвалась в мусор.
- **Стены и потолок** — клипы `clip-path`, сходящиеся в ту же точку схода
  (для плоских затенённых поверхностей это визуально то же, что повёрнутые
  плоскости, но не может пересечь камеру), плюс SVG-линии плинтуса, карниза
  и панельных стыков боковых стен — именно они делают геометрию читаемой.
- **Материалы** — CC0-текстуры Poly Haven (`herringbone_parquet`,
  `marble_01`, `dirty_carpet`), сжатые в 512px WebP (32/11/66 КБ) в
  `public/textures/`; тонируются под тему через `--floor-tint`. Старые
  JPG-плиты не выброшены: они стали дальним планом задней стены (панели,
  бра, панорама города у sapphire) под размытием.
- **Глубина** — отражение стола на полу (сила по теме и физически
  мотивирована: полированное стекло у neon 0.45, ковёр у burgundy 0.1),
  контактная тень, DOF по дистанции, отражения ламп полосами *внутри*
  плоскости пола (сходятся сами), виньетка одной маской вместо шести
  чёрных слоёв.
- **Свет реагирует на игру, камера — нет**: overhead cone ярче на своём
  ходу, вспышка на взятке, тёплый на победе, холодный на поражении/таймауте
  — только `opacity` и цвет, никакого дрейфа комнаты; при reduced-motion
  свет статичен.
- **`roomQuality`** (`auto|high|medium|low`, контрол в поповере настроек):
  `low` убирает все `blur()`-слои и отражение, `auto` выбирает тир по
  `hover: none` и `hardwareConcurrency`. Текстуры активной темы
  предзагружаются, смена темы — кроссфейд, а не жёсткий свап.
- Стол чуть уменьшен (88cqw/74cqh вместо 94/78) — иначе комнате физически
  негде было показаться.
- **Второй ряд свотчей в настройках** переключает на старый плоский фон
  (`room/LegacyBackdrop.tsx`) на той же теме — чтобы сравнить «до/после» в
  один клик. Компонент заморожен (старые цвета тем инлайном, а не через
  `--room-*`, которые теперь принадлежат 3D-комнате) и существует только для
  сравнения — можно удалять вместе с `roomStyle`, когда выбор сделан.
- **Мобильный лэйаут**: боковые панели прячутся `<1100px`, свёрнуты в
  bottom sheet по кнопке в хедере; на тач-устройствах (`hover: none`) карты
  играются в два тапа (первый — выбор/поднятие, второй — ход), чтобы не
  ходить случайно; короткий landscape (`height < 480px`) дополнительно
  сжимает HUD/руку через `useStageRows()`.
- **Доступность**: `:focus-visible` везде на `--accent-ring`, ambient-пульсы
  и вспышки **полностью** (не только `duration: 0.01ms`) отключаются при
  `prefers-reduced-motion`/ручном оверрайде.
- Починена вложенная кнопка в `LobbyScreen` (`<button>` внутри `<button>` —
  невалидный HTML): строка стола теперь `<div role="button" tabIndex={0}>`
  с обработкой `Enter`/`Space`.
- **Стол уезжал вверх и обрезался на вьюпортах ниже ~780px** (например
  ноутбук 1280×800 после вычета хрома браузера). Причина: у боковых
  `aside` не было определённой высоты, поэтому `max-h` панелей не имел базы,
  стопка панелей переполняла строку стола, строка становилась прокручиваемой
  несмотря на `overflow-hidden`, и первый же скролл по фокусу утаскивал стол
  за край. Исправлено `inset-y-2` вместо `top-2`.
- **Компактный тир сетки для низких вьюпортов** (`h < 780`): панель торга
  уходит внутрь строки стола вместо своей grid-строки, оба сиденья
  компактные, HUD/рука ниже — иначе на 700px контента фиксированные строки
  съедали 500px и столу оставалось 200.
- HUD-пилюли больше не переносятся на вторую строку (на 390px «Козырь»
  налезал на аватар соперника) — ряд `flex-nowrap`, «Болты» скрыты `<640px`
  (они есть в панели счёта).

## 🚧 Осталось / известные пробелы

Сознательно вне скоупа:

- Кастомные иллюстрации аватаров (сейчас — DiceBear-заглушки по seed).
- Авторизация, платежи/баланс, база данных, персистентность между
  рестартами сервера (всё in-memory).
- Watch/Waiting-list в лобби, несколько вариаций stakes/типов игр —
  только текстовые метки.

Не вне скоупа, но не сделано / стоит держать в фокусе следующего захода:

- **4 JPG-плиты тем остались JPG** — но проблема разрешения снята иначе:
  они больше не растягиваются на весь кадр, а кропаются в панель задней
  стены под размытием, где их 1024px хватает с запасом. Материалы, которые
  реально нужны в высоком качестве (пол), тайловые и лежат в WebP.
- **Комната и стол не делят один CSS `perspective`**: комната full-bleed (её
  должно быть видно за HUD и рукой), стол живёт в строке `felt` сетки, а
  общая камера означала бы один элемент-родитель для обоих — то есть
  комнату внутрь строки стола и плоский чёрный за HUD/рукой. Вместо этого
  они согласованы художественно, инвариант описан в `roomGeometry.ts`. Если
  когда-нибудь захочется буквально общую камеру — это переработка сетки.
- **Тесты `TurnTimerService`/gateway целиком не покрыты** — сами классы
  используют `@Injectable`/decorators из `@nestjs/*`, которых нет в
  зависимостях корневого Vite/Vitest-проекта (server — отдельный пакет со
  своим `node_modules`, без `reflect-metadata` в корне). Решение: вся
  *логика* решения (что делать по таймауту) вынесена в
  framework-free `turn-timer-logic.ts` и `rate-limiter.ts`, они
  протестированы напрямую; обвязка setTimeout/Map в самих сервисах — нет.
  Чтобы закрыть до конца, нужен отдельный `server/vitest.config.ts` +
  `reflect-metadata`/`@nestjs/testing` в devDependencies сервера.
- **Нет CI** (GitHub Actions) — `lint`/`test`/`build` гоняются локально.
- **Нет e2e/визуальных тестов** — ручная проверка (см. чек-лист ниже).
- **`DealerButton.tsx`** остаётся отдельным неиспользуемым компонентом,
  дублирующим инлайн-бейдж раздающего в `SeatPod` — стоит либо unify, либо
  удалить файл.

## Ручной чек-лист (разрешения × темы)

Проверить на 360×640 (mobile), 768×1024 (tablet), 1280×800, 1920×1080,
2560×1440 — на каждой из 4 тем (Neon/Sapphire/Emerald/Burgundy).

Прогнано headless-Chrome через CDP (скриншот + замер геометрии DOM) на
390×844, 1280×800, 1920×1080, 2560×1080 (21:9) и 2560×1440: горизонт выше
дальнего рейла на всех, скролла нет, `document.scrollHeight` равен вьюпорту.
Остальные комбинации — вручную:

- [ ] Стол не обрезается и не вызывает скролл страницы.
- [ ] Горизонт комнаты выше дальнего края стола (стол не «протыкает» стену).
- [ ] Пол ярче не становится, чем сукно — стол остаётся самым светлым
      объектом кадра.
- [ ] `roomQuality: low` — комната всё ещё освещена и объёмна, просто без
      размытий и отражения.
- [ ] HUD-пилюли (счёт/болты/козырь) не переносятся криво на узких экранах.
- [ ] Рука карт помещается по ширине, веер не наезжает на края экрана.
- [ ] `<1100px`: боковые панели скрыты, кнопка меню открывает bottom sheet.
- [ ] Landscape-телефон (`height < 480px`): HUD и рука компактные, стол не
      сжат до нечитаемого состояния.
- [ ] Кольцо хода тикает синхронно с реальным временем, краснеет `<5с`.
- [ ] Настройки: смена темы/звука/громкости/подсказок применяется сразу и
      переживает `F5` (localStorage).
- [ ] `?` открывает/закрывает шпаргалку горячих клавиш.
- [ ] Победа в раздаче — «+1» и вспышка на аватаре победителя; конец матча
      — конфетти при победе, оверлей с корректным счётом при поражении.

## Как проверить

```bash
# сервер
cd server && npm run dev

# клиент (второй терминал, из корня)
npm run dev
```

Откройте **две вкладки** (у каждой свой `sessionStorage`), сядьте за один
стол и пройдите полный круг: раздача → торг → ход → сбор взятки → конец
раздачи/матча. Проверьте эмоции (клик по эмодзи в одной вкладке должен
всплыть у аватара во второй) и не выжидайте больше 20с на своём ходу —
таймер сходит за вас (авто-пас/случайная карта).

Либо быстрее — одна вкладка, кнопка **«🤖 Играть с ботом»** в лобби.

```bash
npm test        # shared/game + framework-free server modules (turn-timer-logic, rate-limiter)
npm run lint    # eslint (antfu config)
npm run build   # tsc -b && vite build
```
