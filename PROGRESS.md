# Статус проекта — Билот 1×1

Последнее обновление: 5 августа 2026.

Онлайн-белот 1×1: React + Vite + Tailwind + Motion + Zustand на клиенте,
NestJS + Socket.IO на сервере, общее игровое ядро в `shared/game` (Vitest).

## ✅ Сделано

### Игровое ядро и сервер

- Полные правила Белота 1×1: раздача 6 → открытая карта → классический
  торг (круг 1 «взять/пас», круг 2 «назвать другую масть/пас», иначе
  пересдача) → добор до 9 (прикуп 6) → игра до последней взятки.
- Подсчёт очков (162 → 16 пунктов, округление «на 6»), объявы (белла,
  терц, 50/100, четвёрки, шестерка простая, билот), болты, ничья по
  пунктам, аннулирование объявов.
- `shared/game` — чистое ядро без UI-зависимостей, покрыто Vitest
  (`rules.test.ts`, `points.test.ts`, `anim.test.ts` — 16 тестов, все зелёные).
- NestJS-гейтвей (`server/src/game.gateway.ts`): валидация входящих
  сообщений, одна сессия — один стол, `OnGatewayDisconnect` с grace-периодом
  на реконнект, восстановление приватной руки по сессии.
- `LobbyService` / `MatchService` / `SessionService`: жизненный цикл
  матча (создание/окончание/очистка), авторизация действий по seat,
  санитайз имени игрока, единая сессия на стол.
- Событийный протокол анимаций: сервер диффует предыдущее/текущее
  состояние (`shared/game/anim.ts` → `deriveAnimEvents`) и шлёт клиенту
  список событий (`clear_table`, `deal`, `opp_deal`, `face_up_show/hide`,
  `bid_ui`, `play`, `trick_collect`, `hand_end`, `sync`) вместо того, чтобы
  клиент угадывал анимацию по дельте состояния.

### Клиент — общее

- Русская локализация всего UI (`src/ui/i18n/ru.ts`), включая лобби,
  стол, ошибки сервера.
- `NameGate` — экран ввода имени перед лобби, имя живёт в
  `sessionStorage` и синхронизируется с сессией на сервере.
- Клиентская очередь анимаций (`animationQueue.ts`) с `reset()` для
  корректного прерывания при реконнекте/снапе состояния — старые
  анимации не «доигрывают» поверх нового состояния.
- Обработка ошибок сервера как всплывающий тост с возможностью скрыть.
- `prefers-reduced-motion` уважается глобально: `MotionConfig
  reducedMotion="user"` на уровне приложения + все паузы в скрипте
  анимаций схлопываются в 0.

### Лобби

- Убран весь покерный «шум» (Balance/Deposit и т.п.), список столов,
  фильтры Full/Empty, статус Live/Waiting/Open.
- Мини-превью стола в сайдбаре теперь использует тот же процедурный
  `TableSurface`, что и сам матч (единый визуальный язык).

### Стол — редизайн «Emerald Room» (казино-уровень)

- **Процедурный стол** ([`TableSurface.tsx`](src/ui/match/TableSurface.tsx)):
  кожаный рейл со скосом и контактной тенью, фетр с верхним софитом,
  `feTurbulence`-зерно текстуры, золотая инкрустация, свой бренд-медальон,
  гравировка козыря. Растровый `table.png` (портретный, с чужим лого)
  удалён полностью.
- **Композиция без скролла**: `MatchScreen` на `grid-rows-[auto_1fr_auto]`
  в `h-dvh`; стол вписывается в отведённую область по обеим осям через
  `containerType: size` + `cqw/cqh` — никогда не обрезается и не
  выталкивает страницу в скролл.
- **Свой SVG-набор из 24 карт** (`src/ui/cards/`): свои path для мастей,
  раскладки пипов 9/10, крупный туз в золотом ободке, минималистичные
  монограммы J/Q/K с орнаментальной рамкой, новая рубашка (изумруд + золотая
  решётка + медальон). Старые PNG карт удалены.
- **Честный 3D-флип**: `PlayingCard` рендерит `CardFace`/`CardBack` как два
  лица одного контейнера (`transform-style: preserve-3d` +
  `backface-visibility: hidden`), а не имитирует флип поворотом одной
  картинки.
- **SeatPod** (замена `PlayerSeat`): золотое кольцо аватара, SVG-кольцо
  хода (косметический индикатор «живого» стола, не серверный таймаут),
  бейдж раздающего и бейдж взявшего (корона), бабблы объявлений всплывают
  прямо над подом игрока.
- **Мебель стола**: `TrickPile` (стопки взяток растут у стола и коротко
  подсвечиваются при сборе), `KittyStack` (веер прикупа с бейджем-счётчиком
  вместо текста), латунные HUD-пилюли, переключатель темы стола в хедере.
- **Анимации**: раздача летит дугой из виртуальной точки колоды
  (`x/y/rotate`), сбор взятки уезжает направленно к стопке победителя с
  поворотом.
- **3 темы стола** (Emerald / Sapphire / Burgundy) через
  `data-table-theme` и CSS-токены `--felt-*` / `--rail-*` / `--gold-*` в
  `src/index.css`, сохраняется в `localStorage`.
- **Адаптив**: размеры карт через `clamp()` (плавно от >=1280px до <768px),
  раскладка изначально вертикальная (соперник сверху / стол / рука снизу).
- `npm run lint`, `npm run build`, `npm test` — зелёные после редизайна.

## 🚧 Осталось / известные пробелы

Сознательно вне скоупа (зафиксировано в исходных планах — MVP и
казино-редизайн):

- Звук/музыка.
- Настоящий 3D/WebGL-стол (текущий — процедурный CSS+SVG, не canvas/3D).
- Кастомные иллюстрации аватаров (сейчас — DiceBear-заглушки по seed
  от имени игрока).
- Эмоции/чат за столом.
- Авторизация, платежи/баланс, база данных, ИИ-бот, Watch/Waiting List
  логика (в лобби остались только UI-заглушки).

Не вне скоупа, но не сделано и стоит держать в фокусе следующего заезда:

- **Таймер хода — только косметика.** SVG-кольцо в `SeatPod` играет
  визуально «живой стол», но не связано с реальным серверным таймаутом:
  автопаса/технического поражения по истечении времени нет.
- **Гео-таргетинг геометрии сбора взятки приблизительный.** Карты летят
  «в сторону» стопки победителя (лево/право + поворот), но не в точный
  пиксель позиции `TrickPile` — при желании можно прокинуть точные
  координаты через `ref`/`getBoundingClientRect`.
- **Нет персистентности матчей/лобби** между перезапусками сервера — всё
  in-memory (ожидаемо для MVP без БД, см. «вне скоупа»).
- **Нет CI** (GitHub Actions) — `lint`/`test`/`build` гоняются только
  локально/руками.
- **Нет автоматизированных e2e/визуальных тестов** стола (только ручная
  проверка двумя вкладками: раздача → торг → ход → сбор взятки → итог
  раздачи).
- **DealerButton.tsx экспортирует отдельный компонент**, но фактически
  дублируется инлайн-версией бейджа раздающего внутри `SeatPod` — стоит
  либо унифицировать (`SeatPod` использует `DealerButton`), либо убрать
  дублирование.
- Одна ставка/один тип стола в лобби — нет реальных вариаций stakes/типов
  игр, только текстовые метки.

## Как проверить

```bash
# сервер
cd server && npm run dev

# клиент (второй терминал, из корня)
npm run dev
```

Откройте **две вкладки** (у каждой свой `sessionStorage`, значит и своё
имя/сессия), сядьте за один стол и пройдите полный круг: раздача → торг
→ ход → сбор взятки → конец раздачи/матча.

```bash
npm test        # shared/game — правила, очки, диффер анимаций
npm run lint    # eslint (antfu config)
npm run build   # tsc -b && vite build
```
