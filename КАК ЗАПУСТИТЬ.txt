КАК ЗАПУСТИТЬ БЕЛОТ
===================

(English copy: HOW-TO-RUN.txt — use START.bat if Cyrillic names break in zip)

Что поставить ОДИН РАЗ (потом не нужно):
  1) Node.js LTS  — https://nodejs.org  (кнопка LTS)
  2) Docker Desktop — https://www.docker.com/products/docker-desktop/
     После установки Docker должен быть ЗАПУЩЕН (иконка кита в трее).

Запуск:
  • Windows — дважды кликните START.bat  (или ЗАПУСК.bat)
  • Mac     — дважды кликните START.command
    (первый раз на Mac: правый клик → «Открыть», если система ругается)

Что сделает START сам:
  • поднимет Postgres в Docker
  • поставит зависимости (первый раз — несколько минут)
  • создаст БД и пользователя admin / admin
  • запустит сервер + клиент и откроет браузер

Вход в игру:
  Логин:  admin
  Пароль: admin

Играть с ботом:
  В лобби кнопка «Играть с ботом» — без денег, стол стартует сразу.

Адрес: http://localhost:5173

Остановка:
  • Windows — STOP.bat
  • Mac     — STOP.command

Отправить другу архив:
  кликните PACK.bat → рядом с папкой появится belote-for-friend.zip

--- Если пишет «сервер не запустился» ---
1. Docker Desktop должен быть ЗАПУЩЕН (иконка кита). Без него нет БД
   на порту 5433 — NestJS падает с ошибкой подключения к Postgres.
   Это самая частая причина на старом ЗАПУСК.bat.
2. Закройте старые окна Belote, нажмите STOP.bat, потом снова START.bat.
3. Смотрите окно «Belote Server» — там реальная ошибка.
4. Или файл server-start.log в папке проекта.
5. Жёсткий фикс: удалить папки node_modules и server\node_modules,
   потом снова START.bat (поставит заново).
